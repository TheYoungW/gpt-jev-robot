# 本次关键决策与实测记录

这些是便于复盘的任务级摘要：观察到了什么、据此采取了什么动作、结果如何。不是内部思维链，也不替 Jev 编造解释。

## 建模

用户指定 URDF 的网格相对路径失效；在配套 SDK 中找到同名网格。保留 URDF，生成 MJCF 时解析网格路径。原始 tool0 与 CAD 指尖中心存在明显偏移，因此增加独立仿真 TCP，并保留原产品坐标。

## 抓取与路径

先在左臂验证一个物体的“闭合—试提—转移—松开”。接触记录显示左右指垫接触物体，试提时物体随夹爪上升，松爪后由盘底支撑。没有使用焊接约束。

早期连续抓取遇到 IK 冗余分支和腕关节限位问题。加入限位方向的冗余关节优化、关节命令插值，并将暂定场景布置到经验证的可达区域。早期一次运行还在降低时失去夹持，流程按接触检查停止。这些调参过程不能当作独立统计试验。

最终场景仍是人工布置的已知颜色演示。通用随机场景、复杂遮挡和任意物体抓取尚未验证。

## Jev 输入

第一次完整在线尝试中，Jev 选择 approach，但 confidence=0.52，低于固定阈值 0.55，系统转入观察并停止。原始返回保存在 `examples/development/initial_low_confidence.jsonl`。

输入缺少清楚的夹爪/动作阶段描述。随后从实际执行结果整理简短状态，例如“夹爪张开，尚未接近目标”“试提已完成且双侧仍有接触”。没有降低置信度阈值。第二次在线演示连续通过 24 个动作决策。

这说明结构化决策层需要状态语义和前置条件；坐标与历史列表本身不总能让动作条件明确。它不证明 Jev 的泛化成功率。

## 最终验证

Agent 查看中央相机与全景最终画面，确认三种颜色的物体都在盘内、原抓取区域已清空、夹爪退开。再对该状态提交 finish/observe 选择：Jev 返回 finish，confidence=0.96。

独立物理检查验证整个几何边界在盘内、盘底接触、无指垫接触、线速度/角速度趋近零。这个检查使用仿真真值，并单独标明。

本次完成的是分层仿真原型和一条调试后的成功演示，不是论文级性能评估。下一步应固定版本、加入扰动，再做配对对照实验。
