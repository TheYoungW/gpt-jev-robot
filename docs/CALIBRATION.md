# 相机与坐标系

world：X 指向桌面前方，Y 指向机器人左侧，Z 向上；距离为米，角度为弧度。

中央相机设在 `(0.80, 0, 1.55)`，朝向桌面 `(0.36, 0.06, 0.64)`。这是暂定的中央支架/俯视安装，后续可以修改 `scene.py`。

左右相机分别附着在 `l-link7`、`r-link7`，局部位置 `(0.055, 0, -0.085)`，朝向夹爪工作区域。`overview` 是录像视角，不计入三路机器人传感器。

## 每次观测导出的标定

- 960 × 720 像素。
- 由垂直 FOV 推出焦距，`fx = fy = H/(2 tan(fovy/2))`。
- 像素中心约定：`cx=(W-1)/2`，`cy=(H-1)/2`。
- `T_world_camera` 使用 OpenCV 相机轴：X 向右、Y 向下、Z 向前。
- MuJoCo 相机局部 +Y 向上、-Z 向前，因此旋转右乘 `diag(1,-1,-1)` 转换。
- 深度是沿相机光轴的米制深度，不是从相机到表面点的欧氏距离。

反投影：`p_camera = depth * inv(K) * [u,v,1]`，再应用 `T_world_camera` 得到 world 点。腕部相机外参随关节运动变化，每次观测都重新导出，不能只保存启动时的一份外参。

仿真优势是可直接得到一致、同步、可验证的 RGB-D、内外参和独立真值。它让几何/策略问题易于分开调试，**不意味着实机手眼标定、时序误差和相机畸变可以省略**。

## TCP 差异

原始 `l-tool0` 相对 `l-link7` 的位置约为 `(-0.00238,-0.35727,-0.18025)`，右侧 tool0 有镜像 Y 偏移。这个坐标与 CAD 网格中实际夹爪中心不一致：指爪网格自身携带约 0.35 m 的局部偏移。

因此增加 `l_tcp` / `r_tcp` 仿真 site，位于 link7 的 `(-0.002,0,-0.155)`。原始 tool0 和 URDF 文件保持不变。调用本仓库 `move_to` 使用的是新仿真 TCP，不能把它直接当成实机产品 TCP。

为避免 CAD 凸包产生错误接触，使用细长盒体近似指尖摩擦垫，保留原网格外观。对装配上相邻但 kinematic body 不直接相邻的腕部 link5/link7 排除内部碰撞。模型修改、接触参数和动力学近似均在 `scene.py` 中可审查。
