# 实验设计与研究边界

## V2 格式与决策模型的分别验证

使用配对的未知物体布局，并对决策会话隐藏生成参数。保持相机、动作范围、物理参数和验收标准相同。

| 组别 | 输入 | 选择器 | 比较目标 |
| --- | --- | --- | --- |
| A | 自由文本表达的相同事实、参数和条件 | Jev | 与 B 比较表达格式 |
| B | V2 结构化事实、参数和条件 | Jev | 与 C 比较选择器 |
| C | 与 B 完全相同的 V2 状态与候选 | 当前会话 Agent | 不使用 Jev 的对照 |

A 的文本应从同一事实记录中确定性生成，不加入推荐答案、不删掉不利信息。固定 Jev 模型版本，随机化候选编号/顺序以检查位置偏差，保留原始返回。离线同一观测比较和在线闭环试验分开统计；在线各组选择后会产生不同后续画面，不能声称它们一直面对相同状态。

信息提取用独立标注的图片判断遗漏、错误、unknown 的适当性和前后状态识别；仿真真值只给评估器，不能直接将“物理上成立”当作“图片中可见”。决策统计不合条件选择率、门控率、滑落识别与恢复率、最终稳定收纳成功率、token 和延迟。记录墙钟时间并单列暂停，不能用加速视频长度代表完成速度。

已完成[第一次预注册的局部决策试验](../experiments/results/v2_pilot_01/REPORT.md)：12 个状态、72 次真实 Jev 调用，文本/JSON 组单步物理进展率均为 13.9%，没有发现动作效果提升。C 为有信息条件偏差的会话参考组，不是严格隔离的模型比较。完整闭环抓取与独立盲评仍未完成。历史 39 次决策属于 V1。

## 原始总体实验计划

研究假设：Agent 负责视觉解释和候选动作，Jev 负责短小的结构化选择，有机会减少每步开销，并通过置信度门控改善错误处理。需要实验验证，不能用一个演示视频宣称成立。

建议对照：

| 组别 | 视觉与候选动作 | 下一步选择 | 用途 |
|---|---|---|---|
| 确定性基线 | 相同 RGB-D 基线与有限流程 | 硬编码阶段 | 验证物理与控制 |
| Agent-only | 当前会话 Agent | Agent | 估计不使用 Jev 的代价 |
| Agent + Jev | 同一 Agent/感知/工具 | Jev + 前置条件 | 检验决策分层 |
| 去除置信度门控 | 同上 | 总执行 argmax | 测量门控的影响 |

每组使用配对初始状态，至少覆盖位置扰动、遮挡、抓空、滑落、盘内空间不足、颜色变化与相机噪声。记录完整试次数，不只展示成功视频。当前有限流程在不确定或失败时停止并交给 Agent，尚未实现这些场景下的自动重抓策略。

指标：释放并退臂后的稳定成功率、物体跌落数、重观察/重抓数、网络延迟、完整墙钟时间、仿真时间、API token、成本（依据当时账单）、confidence 与实际动作结果的可靠性曲线。Jev confidence 描述其选择分布，不能直接称为抓取成功概率。

当前视觉 baseline 依赖颜色与已知尺寸；不能把该结果表述成通用未知物体抓取。仿真精确标定用于调试与评估；需加入噪声和外参偏差后，才能讨论标定误差容忍度。

后续可扩展：实例分割、姿态/抓取候选生成、模型不确定性、碰撞路径规划、双臂协作、实际 RGB-D 手眼标定。上述能力没有在本次仓库中假装实现。
