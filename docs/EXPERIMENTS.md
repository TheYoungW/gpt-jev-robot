# 实验设计与研究边界

研究假设：Agent 负责视觉解释和候选动作，Jev 负责短小的结构化选择，有机会减少每步开销，并通过置信度门控改善错误处理。需要实验验证，不能用一个演示视频宣称成立。

建议对照：

| 组别 | 视觉与候选动作 | 下一步选择 | 用途 |
|---|---|---|---|
| 确定性基线 | 相同 RGB-D 基线与有限流程 | 硬编码阶段 | 验证物理与控制 |
| Agent-only | 当前会话 Agent | Agent | 估计不使用 Jev 的代价 |
| Agent + Jev | 同一 Agent/感知/工具 | Jev + 前置条件 | 检验决策分层 |
| 去除置信度门控 | 同上 | 总执行 argmax | 测量门控的影响 |

每组使用配对初始状态，至少覆盖位置扰动、遮挡、抓空、滑落、盘内空间不足、颜色变化与相机噪声。记录完整试次数，不只展示成功视频。当前有限流程在不确定或失败时停止并交给 Agent，尚未实现这些场景下的自动重抓策略。

指标：释放并退臂后的稳定成功率、物体跌落数、重观察/重抓数、网络延迟、完整墙钟时间、仿真时间、API token、成本（依据当时账单）、confidence 与实际动作结果的可靠性曲线。Jev confidence 描述其选择分布，不能直接称为抓取成功概率。

当前视觉 baseline 依赖颜色与已知尺寸；不能把该结果表述成通用未知物体抓取。仿真精确标定用于调试与评估；需加入噪声和外参偏差后，才能讨论标定误差容忍度。

后续可扩展：实例分割、姿态/抓取候选生成、模型不确定性、碰撞路径规划、双臂协作、实际 RGB-D 手眼标定。上述能力没有在本次仓库中假装实现。
