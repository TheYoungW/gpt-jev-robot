# 机器人机械时序反馈

这是可选的仿真传感记录，不是自动抓取策略，也不改变 URDF、默认姿态或物理控制。`RobotSim(path, telemetry=True)` 开启；默认关闭，旧实验行为保持兼容。

## 记录哪些量

- 左右臂各 9 个关节：实际位置 q、实际速度 dq、执行器贡献的广义力、位置控制目标。
- 关节 1–7 是旋转关节，单位 rad、rad/s、N·m；8–9 是夹爪移动关节，单位 m、m/s、N。
- 指垫内表面沿 TCP 局部 Y 的间隙，单位 m。这个量来自机器人自身几何，不是物体位置估计。
- 100 Hz 采样，保存最近最多 12 秒，压缩存入运行目录的 `robot_telemetry.npz`。恢复会话时只加载与当前状态时间相容的记录。
- 每项摘要包含窗口首尾、极值、窗口最前/最后最多 200 ms 均值。包含时间范围和样本数，不输出没有标定的“抓住概率”。

数组列：时间；左 1–9、右 1–9 的 q；同顺序 dq；同顺序广义力；同顺序控制目标；左右指垫间隙。共 75 列，文件内同时保存关节名称。

`AgentSession.observe()` 在采样开启时把两臂摘要加到 `robot_feedback.mechanical_history`；视觉事实仍由会话 Agent 根据真实图片填写。V2 现有动作门控未因新增字段而改变。CLI 暂未提供启用开关，Python 研究入口可直接开启。

## 含义和限制

这里的广义力是 MuJoCo 执行器输出，不是已经扣除动力学影响的外部接触力；场景启用了重力补偿。位置控制指令也不等于实际位置。不能只看某个力值就断言夹住或夹空。

采样在物理步之后，动力学输出和派生的几何量相对于积分后 q 最多滞后一物理步（当前 2 ms），摘要中明确记录该对齐限制。尚未模拟编码器噪声、电流到力矩标定误差、异步传输或丢包，因此结果不能直接推广到实机。

传感记录不会读取物体位置、质量、摩擦或夹持真值。**现有普通 AgentSession 接触列表仍包含仿真几何名称；不能把这种物体身份信息冒充实机触觉。** 本次对照实验的两组都只收到匿名的左右指垫接触布尔值，物体身份来自视觉描述。

## 实证检查

试验方案见 [TELEMETRY_PILOT_PLAN.md](../experiments/TELEMETRY_PILOT_PLAN.md)。它是与原 V2 动作试验分开的离线夹持判断任务：固定视觉描述、指令和选项，只对 B 增加机械时序摘要。模型回答不会直接驱动机器人；独立评分器在所有回答冻结后执行同一个 20 mm 验证抬升。

图像、机械记录、真实响应、评估标签和[结果报告](../experiments/results/telemetry_pilot_01/REPORT.md)统一保存。当前摘要未显示判断收益，功能保持可选。实验源脚本可用 `--run-dir` 指定新的工作目录，拒绝覆盖已有测试状态和评分。
