# 当前会话逐步看图的收纳实验

日期：2026-09-22。运行目录：`runs/live_visual_01`。模式：`live_conversation_agent_visual_judgment`。

最终独立验收通过：三个物体的完整包围范围均在盘内，由盘底支撑，不再接触夹爪，线速度和角速度低于验收阈值。**这仅表示最终收纳状态达标，不表示三次抓放全程稳定。** 黄色和红色都曾从夹爪滑落入盘，青色保持夹持直到主动松爪。

## 谁做判断

当前会话中的 Agent 在每步后打开 MuJoCo 的实际 RGB 图片，结合机器人自身 TCP 和指垫接触反馈，撰写下一步提案。没有调用颜色检测器、读取深度数组反投影、读取物体真值位姿来决定动作，也没有运行历史八阶段流程。所有动作以米、弧度、world 坐标表达；XYZ 数值是会话依据画面和自身位置提出的运动目标，由 IK 执行。

Agent 提供场景摘要及有限候选，Jev 通过真实 TypeSafe API 选择单步动作。Jev 本身没有读取图片；它的判断受 Agent 对场景的描述和候选设计影响。这个实验不能证明 Jev 比 Agent 自己选动作更有效，也没有证明方法的新颖性。

## 关键观察、动作与结果

步骤编号对应 `agent_steps.jsonl` 的行号。

| 步骤 | 可见证据和任务级判断 | 动作与实际结果 |
| --- | --- | --- |
| 1–5 | 黄色较容易接近；腕部画面用于逐次校正对准和高度 | 接近、下降、闭合，出现双指接触 |
| 6–10 | 首次试提后物体仍在桌面，指垫接触消失 | 明确认定首次抓取失败，松开后更深接近并重抓；第二次试提保持夹持 |
| 11–13 | 横移后黄色旋转、脱离夹爪，已掉入盘内 | 停止按“仍在夹持”处理，打开空夹爪并确认落盘；这次是意外滑落 |
| 14–19 | 红色位于夹指之间，闭合后试提与升高都保留接触 | 抓起红色，准备移向盘中空位 |
| 20 | 网络恢复后，混入网络解释的提案得到 0.50 置信度 | 低于 0.55 阈值，转为观察，没有强行移动 |
| 21–24 | 红色转移后仍被夹持；较大下降被 IK 预检拒绝 | 查看新图后改为更短下降；随后红色滑落入盘，打开空夹爪并记录失败 |
| 25–31 | 青色主体位于夹指间；试提、升高和横移均保持接触 | 按实际画面逐步接近，抓起并移到另外的空位 |
| 32–36 | 青色保持夹持，位于盘内空地上方 | 分次降低，每步复查后再继续；最后主动松爪 |
| 37–39 | 退臂后中央画面能看到三个物体均在盘内 | 移开遮挡，Jev 选择最终验收；独立验收通过 |

这些说明是可核查的观察、决策摘要与结果，不是模型内部思维链。完整提案和下一观测在 `agent_steps.jsonl`，Jev 输入、返回分布和门控在 `decisions.jsonl`。

## 调用、控制和网络记录

- 39 次收到有效响应的真实 Jev 调用；38 个单步执行返回正常，1 个因 IK 不可达返回 `execution_failed`。执行正常不等于抓取成功。
- 其中 1 次低置信度门控为观察。没有用离线策略伪造 Jev 的返回。
- 另有 2 次网络超时，没有执行运动，不计入有效响应的 39 次。首次发生时还没有新增错误事件日志，证据在会话工具输出；第二次在 `events.jsonl` 中记录为 `agent_decision_failed`。没有补造首个事件。
- 本机 TUN 的域名解析导致官方接口超时。核对公共 DNS 并通过 TLS 验证官方域名后，本次临时会话驱动仅对官方主机使用进程内 DNS 覆盖。没有关闭 TLS、改用第三方 API 域名或更改系统网络配置；仓库客户端仍使用官方域名和正常 DNS。网络异常后重新看图再提交提案。
- 验收真值只在最后请求完成和导出报告时读取，没有反馈到中途动作提案。

## 录像与复核

`episode_4x.mp4` 是 MuJoCo 原始渲染的 960×720、30 fps 视频，共 382 帧，容器时长约 12.74 秒。仿真从 0.8 秒到 54.372 秒，逐动作按每 67 个 2 ms 物理步抽帧，段末不足一帧的部分不保留，因此本轮实际约 4.2 倍速。API 等待及会话看图期间仿真暂停，不计入录像。

`before_center.png` / `after_center.png` 可直接对照；`observations/` 保留每步多相机 RGB 和标定。导出包省略体积较大的深度数组和运行状态文件。JSON 中图片路径相对于本目录，SHA-256 可复核原始 PNG。

代码验证：33 项测试通过，MCP stdio 握手、工具列表、带编号观测及旧编号提案拒绝通过。测试没有证明 Agent 判断的泛化能力。当前仅在这一已知场景中完成了一次在线交互；后续仍需要随机物体位置、遮挡、夹持失败及无 Jev 对照实验。
