# V2 官方接口连通性检查

日期：2026-09-23。新运行目录，使用未随机化的原有场景。这不是盲测或完整抓取实验。

会话实际查看了中央和左腕 RGB，按 V2 填写六个目标关系、未知项和图片来源，提供短距离对准、闭爪和重新观察三个候选。候选闭爪因侧面重叠不成立、夹指间关系未知而被本地标为不可执行；对准候选独立通过路径判断和 IK 预检。

官方 Jev 返回 observe，confidence=0.80，概率 observe=0.87、a01=0.13、a02=0.00。没有执行机械运动；随后保存新图片。因此没有视频，也没有请求最终物体真值验收。

本次 model=jev-1.13.0，API 时长约 479 ms，输入 2452 token，输出 43 token。拍摄至提交约 48.04 秒，包含会话查看与工具操作；step 约 0.97 秒，包含预检、请求及反馈保存。不能把这些间隔称为纯推理时间。

完整 API 输入在 decisions.jsonl：含动作参数、默认手臂、坐标单位、计算后的条件、预检及 eligibility，不含 audit_note 或预先推荐结论。agent_steps.jsonl 保留本地审计备注，便于对照检查。observation_receipts 保留图片引用与哈希。

这个样本证明协议能连接真实 API、执行观察并保留证据，不能证明 V2 提升成功率或降低成本。测试中使用的模拟响应仅位于 tests 和临时目录，不混入本记录。
