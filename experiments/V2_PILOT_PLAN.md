# V2 决策对照试验：预先固定的方案

本文件在查看本试验任何 Jev 返回和动作评分之前写入。它是小样本决策试验，不是完整收纳成功率研究。

## 样本与比较

- 12 个物理状态：历史视觉运行第 6、10、12、17、36、38 步之后的六个状态，以及六个新随机布局。
- 历史状态通过记录的真实肌肉命令重新构建，仅用于制作冻结测试状态，不作为本次策略。
- 新布局使用系统随机种子。生成器不输出物体位置或种子；决策会话只打开相机图片与机器人反馈。生成分布和物体类型已知，不能声称独立第三方双盲。
- Agent 在查看任何本试验 Jev 输出之前填写所有视觉事实、候选动作和自己的选择 C。冻结文件哈希。
- A：同一规范化状态逐字段确定性转成文本句子；B：保留 JSON 对象结构。不是比较任意手写摘要；信息内容相同。
- 每个场景三种候选编号/顺序，A/B 使用同一种排列并随机先后请求。模型固定 `jev-1.13.0`，共 72 次调用；网络错误保留，最多只重试一次，绝不以离线结果代替。
- C：会话 Agent 的预先保存选择，与 A/B 使用相同候选、动作条件和执行器。C 不使用 GPT API。

## 主要指标：冻结状态下单步物理进展

每次选择均从同一个物理状态副本执行一个动作。相同动作结果可缓存并明确记录，不重复算作独立试验。所有组使用相同门控；另外保留原始选择、低置信度和非法条件选择。

评分只在所有选择冻结后读取物体真值，且不回传给决策。评分标准：

| 状态 | 单步目标与成功标准 |
| --- | --- |
| H01：首次试提后 | 恢复：夹爪由关闭变为打开，目标仍在原支持面附近（位移 < 10 mm） |
| H02：重抓试提后 | 保持夹持升高：目标升高 ≥ 25 mm、目标与 TCP 位移差 < 15 mm、动作后双指仍接触目标 |
| H03：横移滑落后 | 松开空夹爪：夹爪打开，目标仍在盘内且由盘支撑 |
| H04：红色闭爪后 | 试提：目标升高 ≥ 25 mm、目标与 TCP 位移差 < 15 mm、动作后双指仍接触目标 |
| H05：青色松爪后 | 退臂：TCP 升高 ≥ 30 mm、目标仍在盘内且由盘支撑且不触夹爪 |
| H06：全部放好退臂后 | 完成：执行 finish 且独立收纳验收通过 |
| R01–R06：随机布局 | 对准：TCP 与指定视觉目标的水平距离缩短 ≥ 2 mm，目标位移 < 5 mm，未接触夹爪 |

这些是局部任务进展标准，不等于全程抓取成功率。每个状态三次排列取均值，不能把排列当作 36 个独立场景。六个历史状态来自同一条轨迹，不能假定互相独立；不确定性估计按七个布局来源聚类（一个历史来源加六个随机布局）。

## 次要指标与统计

- 原始不合条件选择率、门控后 observe 比例、候选排列造成的选择变化。
- API token、延迟、网络失败及试验墙钟时间。C 无可比的 API token/纯模型计算耗时，不能据此推断成本优势。
- 报告 A/B/C 各状态分数和总均值；B−A 用布局来源聚类的配对 bootstrap（10000 次、固定分析种子）给出 95% 区间，并对七个来源的平均差做忽略平局的双侧精确符号检验。错误响应在重试后仍失败时记作未取得进展，并单列错误率。
- C 的选择不作为标准答案；其得分同样来自单步物理结果，因此不计算“与自己一致即正确”的准确率。
- 格式实验共享一份 Agent 提取结果，无法检验视觉提取准确率本身。视觉事实由同一 Agent 标注，暂无独立图像标注者；结论必须保留这项限制。

## 不修改结果的规则

不根据返回结果更换候选、改变评分阈值、剔除不利状态、调整提示词后覆盖原试验，或追加样本直到出现显著性。发现协议缺陷照常计分，并单独报告，修复必须使用新的试验编号。公布代码、冻结提案、原始响应、评分、失败和时长。结果不支持提升时明确报告。
