# 机械时序反馈配对试验：预先固定的方案

本方案在制作测试状态、查看新物理评分或调用本轮 Jev 前固定。测试的是夹持判断，不是完整收纳成功率；不修改上一轮结果。

## 配对比较

- A：Agent 对真实中央/腕部图片的同一份描述、TCP 及匿名双指接触反馈。
- B：完全相同的 A 输入，加机器人关节位置、速度、执行器广义力及夹爪开口的时序摘要。
- 两组均保留相同的上一动作、单位、判断定义和选项。A 已有接触传感，不称为纯视觉。
- 判断选项为：保持夹持（可继续短距离验证抬升）、未保持夹持（需重新观察并准备恢复）、证据不足（observe）。本试验只咨询，不直接执行模型选择。不是 V2 动作提案，不绕过其门控。
- 专用判断问题使用相同中性指令，不提供推荐答案或物体真值。Jev 不读取图片。模型固定 jev-1.13.0，置信度 <0.55 记为 observe，同时保留原始选择。
- 每个状态三个编号/顺序排列，A/B 配对且随机请求先后：24 状态 × 3 × 2 = 144 次真实调用。失败最多重试一次，错误计入分母。

## 状态与传感

- 六条离线测试轨迹，重放历史视觉运行的前 12 个实际肌肉命令，仅用于建立物理测试状态，不作为新抓取策略。
- 第一条原参数；其余五条由预先固定的随机生成器改变物体摩擦（基准乘 0.4–1.6）、质量（乘 0.8–1.5）及初始 XY（每轴 ±4 mm）。随机种子保存在不提供给决策环节的 setup 文件中。全部变动只在初始场景创建时做，不在操作中改物体。
- 每条固定取第 6、10、11、12 步后的状态，共 24 个。保留所有结果，不因样本不够平衡而替换；控制错误也保留并报告。
- Agent 在打开本轮物理评分前检查全部新图片，保存带来源的视觉描述。共享的描述在 API 前冻结；不为 B 重写。历史轨迹与失败已知，标注者不是独立盲评者。
- 机械采样为 100 Hz、最近最多 12 秒；读取机器人自身 q、dq、执行器广义力和指垫间隙，不读取物体位姿、名称或真实接触力作为新增信号。100 Hz 是仿真采样率，不是模型决策频率。
- 双指接触只暴露每个指垫有无接触，不暴露碰到哪个仿真物体。广义力是仿真执行器输出，非实机测量或已分离的外力。模拟有重力补偿，物体轻，不能保证手臂力矩有足够信息。
- 原始时序、最新 RGB、时间戳和摘要一起归档。只评估本轮确定的采样/摘要组合；不宣称分离验证每个传感器的贡献。

## 独立物理标签与指标

所有图像描述和模型选择冻结后，才读取评估器真值。每个冻结状态建立独立副本，执行同一个向上 20 mm 的验证动作。记录：当前及动作后目标是否同时接触两指、物体上升是否 ≥10 mm、物体与 TCP 位移差是否 <10 mm。四项均满足且动作执行成功，标签为 retained，否则 not_retained。控制不可达/执行失败为 unscorable，单列，不能当成未夹住。

标签衡量的是在该小幅验证动作中保持夹持，不等同于任意后续搬运稳定性。observe 不算分类正确，但单列覆盖率与在确定回答中的准确率；避免一直 abstain 获得虚假成功率。

- 主要指标：门控后判断准确率 B−A（每个状态的三个排列先求均值）。
- 次要指标：失败却判断 retained 的比例；真正 retained 却判断失败的比例；observe 比例、原始选择准确率、token 和 API 延迟。
- 同一条轨迹的四个状态相关。按六条轨迹进行配对 cluster bootstrap（10000 次，分析种子 20260924）及来源级双侧精确符号检验，不将 72 次排列当独立样本。轨迹共享布局/脚本，是弱泛化的六种条件，不是六个独立任务分布。
- 不测试发现滑落的时间延迟或首次抓取成功率；端点样本不能支持这些结论。
